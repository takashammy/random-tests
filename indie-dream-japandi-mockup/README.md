# Dreamin' Indie — Japandi dark mockup

Local **theme-only** mockup of [indie-dream.vercel.app](https://indie-dream.vercel.app/).

- Does **not** change the deployed app
- Not for deploy — preview only
- Same information architecture and mobile shell; new Japandi dark high-contrast palette, type, and surface treatment
